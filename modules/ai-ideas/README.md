# 创意集市

`/ideas` 按北京时间自然日，把本站公开新闻整理为最多 5 个面向国内个人与小团队的 AI 应用创意。每条包含客群、问题、做法、新闻触发条件、第一步、验证步骤、继续/停止信号、投入粗估、收费假设、不确定因素及来源。点子属于 AI 推演，不代表已经验证的需求或收益。

默认打开今天，可使用日期控件或 `?date=YYYY-MM-DD` 回看。无当日新闻时展示空态与往期入口，不拿其他日期替代。新闻依据撤回、删除或更正后，相关点子会从公开页面隐藏。

卡片默认展示「为什么提出这个创意」、来源名称、新闻日期和原文链接；展开后查看新闻摘要与验证方案。来源说明只支持新闻中的能力变化，客户需求、用途与收费方式属于待验证的 AI 推演。本模块读取本站已采集的摘要，不在生成时自行联网搜索或进行市场调查。

管理：`/admin/ideas`。管理员按日期提交生成任务，带 CSRF 与审计；HTTP 只入队，worker 执行模型请求。后台模型设置新增「创意集市」步骤，默认继承 `LLM_MODEL`。同一天相同资料、提示词和模型配置复用结果。新资料可手动重新生成；模型回执和既有预算限制仍有效。

每日任务需要 `AI_IDEAS_DAILY_ENABLED=true`、`MODEL_CALLS_ENABLED=true` 和 worker 运行，每晚 21:30（北京时间）执行。开发默认关闭。采集需独立启用；没有新闻不会调用模型，不自动补生成错过的日期。

独立执行一天的后台任务（不启动其他采集/翻译队列）：

```sh
node --env-file-if-exists=.env modules/ai-ideas/cli.ts 2026-10-14
```

调用真实模型仍需该进程的 `MODEL_CALLS_ENABLED=true`。Docker 可用 `docker compose run --rm --no-deps -e MODEL_CALLS_ENABLED=true api node modules/ai-ideas/cli.ts <日期>`，只临时打开该进程的开关。

数据存在模块表 `ai_idea_editions`（迁移 0090）。新闻输入和公开输出统一经 `packages/backend/src/publication/ideas.ts`；先从当天最多 300 条资料中优先精选、按事件去重，再取最多 32 条；不读取来源全文。模型只接受输入中的 1–3 个来源 ID，不支持外部自编链接。事实依据快照以 hash 保存，公开读取时重新核对。

页面使用站点现有主题；电脑「内容」和手机「我的」均有入口。失败不发布半成品，原先仍有有效依据的点子保留并标记状态。运行任务超过 15 分钟视为未完成，管理员可重试；队列与 session lock 防止同日并发调用。

测试：模块测试使用隔离 PostgreSQL 与本地模型 stub，覆盖日期边界、公开性、回执复用、并发、更正/撤回、伪造引用、鉴权、CSRF 和排程开关。浏览器测试覆盖电脑/手机/WebKit、空态、日期切换、展开、错误恢复及后台提交。
