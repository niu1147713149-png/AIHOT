# Skills 市场交互合同

本次按已接受的实现方案在本地交付。复用 AIVANE 应用壳、语义颜色、字体、8/12px 控件与卡片圆角；不生成设计位图。中文介绍保留原 Skill 名与可追溯来源，热度使用带日期的来源快照。

| 页面 | 主要行为 | 状态与反馈 |
|---|---|---|
| /skills | 搜索、用途/客户端筛选、热门/精选/更新排序、分页 | URL 保存筛选；加载指示；首次空和无结果分别说明；清空筛选；错误可重试 |
| /skills/:id | 阅读用途和示例，选择客户端/安装范围，复制，查看来源 | 复制成功/失败消息；不可安装信息明确；下架 404；长命令换行 |
| /skills/rules | 查看来源、热度统计范围与核验方式 | 可返回列表，手机可读 |
| /admin/skills | 查询所有状态、预览 JSON 导入、确认新增 | 校验失败保留输入；预览列出条目与重复；明确确认后写入，成功刷新 |
| /admin/skills/:id | 编辑中文信息/分类/依赖/来源/安装元数据，精选与上下架 | 表单校验、保存中禁用、成功与失败反馈、版本冲突、未保存离开确认 |

首版只收公开独立 Skills。桌面工具区和手机“我的”均可到达；新增入口不增加手机底栏 tab。所有按钮使用文本或可访问名称。详情返回保留筛选条件；URL 深链可直接读取。

列表采用紧凑的两栏技能卡片，窄屏单栏。详情在宽屏用正文与安装区两栏，窄屏上下排列。搜索和筛选可换行；320px 不产生整页横向滚动。表单使用现有后台组件、管理员鉴权、CSRF、审计理由及版本校验。

验收覆盖：桌面/手机、浅色/深色、SSR、搜索/筛选/排序/分页/后退、安装范围与复制、无结果/空/错误/404、导入预览/保存/冲突/下架、匿名管理请求拒绝。截图和测试结果记录在同目录 qa-report.md。
