# AIVANE 2026-10-17 发布说明

本批次将此前分别验证的功能按用途提交，统一用于本机与服务器部署。

## 功能变化

- 双语阅读：外文文章默认中英逐段对照，可切换中文与原文；保留图片、代码和目录。全文翻译覆盖允许展示全文的公开历史资讯与非精选文章，补充长文、列表及表格中遗漏的文字。页面阅读不调用模型，补译沿用回执与预算限制。
- 模型榜与 Tibo：显式开启采集与模块同步后，支持服务器地址；公开页面匿名可读，后台继续要求管理员身份。
- Skills 市场：新增 `/skills`、详情、规则及 `/admin/skills`，提供分类、搜索、安装命令、来源与许可。首批目录 33 条，重复导入不覆盖人工编辑；安装量是注明日期的来源快照。
- 创意集市：新增 `/ideas` 与 `/admin/ideas`，从本站当天新闻摘要生成创意，显示推演理由、真实来源、验证步骤与不确定性。新闻发生更正或撤回时隐藏相应创意；生成仅在 worker 或独立 CLI 执行。

客户需求、收费方式和收益没有市场验证，创意页面对此明确标注。当前生成策略未增加新颖性评分或跨新闻组合机制。

## 升级与回退

1. 核对提交版本，备份服务器数据库、`.env`、Compose 覆盖文件与旧应用镜像；使用该提交打包源码并构建镜像。
2. 保留服务器自己的域名/IP、凭据和运行开关；不把本地 `.env` 或整个本地数据库覆盖到服务器。
3. 正常停止旧 worker、API 与 web，运行迁移。0087–0090 仅新增 Skills 与创意表，不删除已有资讯。
4. 先预览再导入首批 Skills，重跑不会覆盖服务器已经编辑的条目。恢复服务后检查公开页、后台鉴权、数据数量和 smoke。
5. 本地已有创意如需迁移，必须逐条核对服务器新闻及其证据 hash，保留原生成日期，不伪装成当日生成；本地模型回执 ID 不应当作服务器回执关联。

新增 `SKILLS_MARKET_SYNC_ENABLED` 与 `AI_IDEAS_DAILY_ENABLED` 均默认关闭。部署应用本身不等于开启新一轮定时采集或付费生成；已有采集和模型设置由服务器原配置决定。日更的启用方式见[创意集市说明](../modules/ai-ideas/README.md)。

回退时恢复之前的镜像引用、源码和 Compose 配置并重启原服务，新增表可以保留。除非另行确认需要回滚业务数据，否则不恢复整库，以免丢失部署后新增资讯。详细操作见[部署说明](deploy.md)。
